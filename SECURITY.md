# Security Policy

## Supported Versions

The following table lists supported project versions for the PythOS project.
 
| Version (vx.x.x)| Supported          |
|-----------|------------------|
|Alpha v2.0.0| Yes ✅ |
|Alpha v1.0.0 (Xmas edition included in support) | Yes  ✅ |
 Indev v2.1.1 (bug fix 1)        |      Yes    ✅          |
| Indev v2.1.1 (beta 1 / stable)        |     No    ❌           |
|  Indev 2.1.0       |           No      ❌   |

## Reporting a Vulnerability

**To report a vulnerability, draft a security advisory or fill out the _Vulnerabillity Report_ issue template.** I will see it when possible and publish a bug fix for it.
