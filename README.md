# PythOS 👨🏻‍💻
The newest way to use Python!

## Requirements ✔️
- Python 3.12 or higher[^1], preferably the latest stable[^2] version from [the Python website's Downloads page](https://www.python.org/downloads/).

- A capable Windows, Linux or M-series/Intel Mac computer. You can also use a Pi[^3].

- A supported operating system, such as:
  - Windows 10 or higher
  - MacOS <10.9 Mavericks
  - A recent[^4] version of a Linux distro. 

## Help
The PythOS Wiki has lots of information to help you get started. If you have any problems, feel free to open up an issue.

[^1]: 3.12 adds multi-line f-strings which are used quite extensively in this project.
[^2]: Stable Python versions will have fewer bugs that may make PythOS inoperable.
[^3]: Tested on a Raspberry Pi 3 A+.
[^4]: It is recommended that get the latest version for the most compatibility, but if it was released within the last 3 years you _should_ be alright. If in doubt, check [the Python website](https://www.python.org/).
